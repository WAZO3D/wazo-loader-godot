# wazo-loader-godot — WAZO3D models in Godot 4, pictures shared

Reads models made in [WAZO3D](https://wazo3d.com) with Godot 4's own glTF importer, and shares each picture
between every model that wears it: a picture already held is not read, decoded or uploaded again.

**Being written.** What it must do is in [`SPEC.md`](SPEC.md), the test files are in [`fixtures/`](fixtures),
and the three.js loader it follows is [wazo-loader-three](https://github.com/WAZO3D/wazo-loader-three).
